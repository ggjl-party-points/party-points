# AI 辅助导入：接入与验收

## 当前状态

本改动先放在独立开发分支，未替换正式网站。电脑执行环境在开发期间断连。
已在隔离的 JavaScript 运行环境中检查新增模块与模拟接口流程；尚未完成 Node.js 全套回归、真实浏览器及真实 CloudBase/DeepSeek 联调，不能视为已上线。

## 工作流程

网页选择 AI 辅助分析 → 本机读取表格与匹配人员 → 只将活动/获奖文字发送到专用云函数 → DeepSeek 提供原文拆分和分类建议 → 网页严格校验原文是否完整 → 管理员逐条选择类别、档位并确认 → 原有导入预览核对身份与重复材料 → 最后一次确认才保存。

- 保留原有规则识别；AI 尚未接通时仍可用原方式导入。
- AI 不能给任意分数。最终分数由当前系统规则按档位确定。
- 不自动接受高置信度建议；每条均须人工确认或显式标记为待审核。
- 待审核材料保留原文，暂不计分。之后在原有审核页处理。
- 先前人工确认且规则一致的同条材料不重复发送。
- 不发送姓名、班级、学号等表格字段；如果这些信息写在活动原文本身中，属于材料文字，仍可能随文字发送，上传前可自行脱敏。
- 分析取消、接口报错、AI 漏字或改写、预览取消，都不写入人员数据。
- 对 AI 导入使用临时副本验证，验证失败不替换现有 APP。历史名单结果保持冻结。
- 不收集、不展示、不记录模型的内部推理内容，仅展示简短分类依据。
- 云函数不读写任何数据库或历史结果，不记录材料和密钥到日志。

## 需要管理员在腾讯云操作的部分

1. 进入原有环境 partypoints-d3g5gwtnz48e590fa，不要新建或更换数据库环境。
2. 新建云函数：party-points-ai-import。
3. 运行时使用 Node.js 20 或更新的兼容版本，入口 index.main，超时设置 90 秒。
4. 将仓库中 cloudfunctions/party-points-ai-import/ 目录的三个文件放到函数根目录：
   - index.js
   - analysis-core.js
   - package.json
5. 在云端安装 package.json 依赖，然后部署。不要把网站根目录当作函数目录上传。
6. 配置这个新函数的环境变量：
   - DEEPSEEK_API_KEY：在腾讯云后台填写实际 API Key，不是密钥 ID。不要提交 GitHub、不要填入网页、不要发送到聊天。
   - ALLOWED_ADMIN_UID：2099738603472580610，与现有系统管理员 UID 一致。该项未配置时函数拒绝所有请求。
   - DEEPSEEK_MODEL：可选，默认 deepseek-flash；也支持 deepseek-v4-pro。先使用默认模型做小样本验证。
7. 只为新增函数配置必要的 SDK 调用权限，不覆盖环境中其他函数的权限，不开启匿名公开 HTTP 入口。
8. 本函数通过 SDK 的运行时身份验证 UID，不接受请求体传来的管理员 UID。控制台直接模拟匿名调用返回 FORBIDDEN 是预期行为。
9. 连接检查应从登录后的网页点击“检查AI连接”，该操作不调用收费模型。

尚未部署函数或缺少环境变量时，网页应明确提示未配置。不能把“网页入口存在”当作 AI 已接通。

## 运行测试

恢复工作环境后，在仓库根目录运行：

    node --test tests/ai-import.test.cjs
    node --test tests/workflow-dom.test.cjs tests/workflow.test.cjs

完整回归测试文件若只保留在现有 D 盘工作目录，先将本分支代码同步到 D:\party point\party-point，保留本机 tests 目录，再执行。不要复制私有收集表或备份到仓库。

## 上线前验收

1. 未登录及非管理员用户被拒绝，改请求体 UID 不可绕过。
2. 无密钥时规则导入仍正常，连接检查不产生 DeepSeek 调用。
3. 用虚构资料测试 2—3 条材料，确认原文、分类、级别、最终分数对应。
4. 明确缺少级别的比赛及未知期刊应提示人工确认，不能自动猜分。
5. 模拟接口失败、停止分析、关闭核对和取消导入，原成员数、积分、名单与历史均不变化。
6. 在核对页选“省级竞赛”，最后保存应为 6 分；AI 返回 999 分也不可改变该结果。
7. 导入同一份已确认材料第二次，应沿用已有确认，不重复加分。
8. 对比前后完整备份，确认只有本次确认的材料与导入记录变化。
9. 完成以上验收后，才将独立分支合并发布。

## 成本与限制

每次请求最多 6 段、单段最多 3000 字、总计最多 12000 字；网页依次请求，不自动重试失败的付费分析。关闭页面不能撤回已发到 DeepSeek 的请求。

云函数内“忙碌锁/每分钟限制”只针对当前复用实例，不能当作跨实例总预算或账单上限。账户余额与其他系统共享；上线后需要查看服务商实际用量。

AI 核对记录会增加备份体积。AI 导入前检查最终数据大小，接近现有单记录容量上限时停止导入，不覆盖人员数据。

## 回退

未合并前正式网站完全不受影响。合并后若需停用，取消“使用AI辅助分析”继续规则导入；也可移除该云函数的 DeepSeek 环境变量，使其仅返回未配置状态。不要删除 app_state 集合或恢复旧备份覆盖新增人员。
